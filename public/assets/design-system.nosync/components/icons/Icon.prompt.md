Cohesive SVG icon set for DriftLands — the 6-tool kit plus resource & HUD glyphs; inherits `currentColor` so it tints to any token.

```jsx
<Icon name="axe" size={24} />
<Icon name="drift" size={20} glow color="var(--drift-corrupt)" />
<Icon name="coin" color="var(--drift-gold)" />
```

Tools: `axe`, `pickaxe`, `rod`, `sword`, `ward`, `sigil`.
Resources: `log`, `ore`, `fish`, `coin`, `drift`.
HUD: `heart`, `leaf`, `bag`, `bolt`, `chevronRight`, `x`.
Props: `size` (default 20), `strokeWidth` (1.75), `glow` (purple drop-shadow), `color`. `ICON_NAMES` / `TOOL_NAMES` are exported lists.
